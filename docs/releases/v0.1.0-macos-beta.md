# v0.1.0-macos-beta — draft pre-release notes

**Draft only: no tag or GitHub Release has been published.** This experimental beta adds native macOS WKWebView support for Typora 1.14.15 on arm64 and x86_64.

## Installation

Quit Typora, extract the beta archive into a local directory, and run:

```bash
plugin/bin/install_macos.sh --dry-run
plugin/bin/install_macos.sh --yes
codesign --verify --deep --strict --verbose=2 /private/tmp/Typora-Plugin-Beta.app
open -n /private/tmp/Typora-Plugin-Beta.app
```

The installer reads `/Applications/Typora.app` only as its copy source and installs into `/private/tmp/Typora-Plugin-Beta.app`. To uninstall:

```bash
plugin/bin/uninstall_macos.sh --app /private/tmp/Typora-Plugin-Beta.app --yes
```

## Included

- authenticated least-privilege Node bridge and WKWebView adapter
- isolated-copy installer, diagnostics, rollback, repeat install, and uninstaller
- ad-hoc development signing workflow
- English and Chinese installation/security documentation
- verified support for `callouts`, `editor_width_slider`, `collapse_paragraph`, `fence_enhance`, `command_palette`, and `markmap`

Compatibility fixes cover UTF-8 encoding spelling, framework startup at WKWebView interactive/complete ready states, unavailable host menu methods, and Markmap outline updates during asynchronous asset loading.

## Evidence

- all six plugins loaded JavaScript, rendered UI, and completed real interactions in Typora 1.14.15
- persistence passed where applicable; command-palette and modifier-click shortcuts passed
- repeated startup passed without console errors, unhandled rejections, or timeouts
- synthetic install/reinstall/uninstall/rollback and deep/strict signing checks passed
- full serialized Node.js 22.23.5 result: 1,671 tests; 1,670 passed, 0 failed, 1 skipped; 16.7 seconds, no hang

## Security considerations

The loopback bridge uses a 256-bit token, exact file-origin validation, method and size allowlists, read-only plugin roots, a configuration-only write root, private file modes, and symlink rejection. It exposes no shell execution. The token must be embedded in the private development bundle, so another process running as the same macOS user can read it; this is a documented same-user trust boundary rather than a security sandbox.

## Limitations

This is not official Typora support, not Apple-notarized, and not a distributable Typora binary. Only 1.14.15 and the six named plugins are verified. A same-user process can read the local bridge token. Install only into the default `/private/tmp` copy and never distribute that app.

See [installation instructions](../macos.md). The package contains no Typora application binary.
