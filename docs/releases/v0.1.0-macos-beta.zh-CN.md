# v0.1.0-macos-beta — 预发布说明草稿

**仅为草稿：尚未创建标签，也未创建或发布 GitHub Release。** 此实验性 Beta 为 macOS arm64/x86_64 上的 Typora 1.14.15 增加原生 WKWebView 适配。

## 安装与卸载

完全退出 Typora，解压 Beta 包后运行：

```bash
plugin/bin/install_macos.sh --dry-run
plugin/bin/install_macos.sh --yes
codesign --verify --deep --strict --verbose=2 /private/tmp/Typora-Plugin-Beta.app
open -n /private/tmp/Typora-Plugin-Beta.app
```

安装器只把 `/Applications/Typora.app` 作为复制来源，实际安装目标为 `/private/tmp/Typora-Plugin-Beta.app`。卸载命令：

```bash
plugin/bin/uninstall_macos.sh --app /private/tmp/Typora-Plugin-Beta.app --yes
```

- 带令牌认证和最小权限文件访问的本地 Node.js 桥接
- WKWebView CommonJS 兼容适配器
- 独立副本安装、诊断、事务回滚、重复安装及可靠卸载
- 本地 ad-hoc 开发签名流程
- Node.js 22.23.5 完整测试：1,671 项，1,670 通过，0 失败，1 跳过，无卡死

## 安全与限制

桥接服务只监听回环地址，使用 256 位令牌、严格文件 Origin、方法/大小白名单、只读插件目录、仅配置可写目录、私有文件权限和符号链接拒绝，并且不提供 Shell 执行。同一 macOS 用户运行的其他进程仍能读取嵌入开发副本的令牌，因此它不是完整安全沙箱。

此版本不是 Typora 官方支持，未经 Apple 公证，也不包含或分发 Typora 应用二进制。仅 Typora 1.14.15 和上述六个插件经过验证。详见[中文安装说明](../macos.zh-CN.md)。
